# X2 Exotics - Freego X2/X2 Pro Parts Store

A modern e-commerce store for selling Freego X2 and X2 Pro parts and upgrades.

## Quick Start

1. Clone the repository:
```bash
git clone https://github.com/x2exotics/x2exotics.git
cd x2exotics
```

2. Install dependencies:
```bash
npm install
```

3. Run development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Features

- ✅ Product catalog with 8 sample Freego parts
- ✅ Shopping cart functionality
- ✅ Product filtering by category
- ✅ Search functionality
- ✅ Responsive design (works on Safari, Chrome, etc)
- ✅ Product detail pages
- ✅ Real-time cart updates

## Deployment

Deploy to Vercel (free):

1. Push to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your repository
4. Click Deploy

## Customization

Edit `data/products.js` to add/modify products with your actual inventory.
